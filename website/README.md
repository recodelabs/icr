# ICR Implementation Guide — website

Docusaurus source for the ICR Implementation Guide, published to
**docs.healthcampaigns.org** (Cloudflare Pages project `icr-docs`).

## Local development

```bash
npm install
npm run start   # dev server with live reload
npm run build   # production build into build/ (validates links; onBrokenLinks: throw)
```

## Deploy

Pushes to `main` that touch `website/**` trigger
[`.github/workflows/publish-docs.yml`](../.github/workflows/publish-docs.yml), which
builds this site and deploys it to Cloudflare Pages. See the design spec and plan under
[`../docs/superpowers/`](../docs/superpowers/).

Content lives in [`docs/`](docs/); the sidebar is autogenerated from the folder
structure and `_category_.json` files.
