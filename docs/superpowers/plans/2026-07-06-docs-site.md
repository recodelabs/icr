# docs.healthcampaigns.org Implementation Guide site — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a Docusaurus "ICR Implementation Guide" site in `website/`, with a real section structure (stub content), that builds cleanly and auto-deploys to a Cloudflare Pages project `icr-docs` (→ docs.healthcampaigns.org) via GitHub Actions.

**Architecture:** A single Docusaurus classic-preset app lives in `website/` at the repo root. It runs in **docs-only mode** (`routeBasePath: '/'`, blog disabled) so the docs *are* the site. Content lives in `website/docs/` with an autogenerated sidebar driven by folder structure + `_category_.json` files. A new GitHub Actions workflow builds `website/` and deploys `website/build` to Cloudflare Pages, mirroring the existing IG pipeline. DNS/custom-domain is a final manual step for the user.

**Tech Stack:** Docusaurus 3 (classic preset, TypeScript config), Node 20, npm, Cloudflare Pages, `cloudflare/wrangler-action@v3`, GitHub Actions.

## Global Constraints

- Node **20** (matches `.github/workflows/publish-ig.yml`).
- Docusaurus app dir: **`website/`** (repo root). Content: **`website/docs/`**. Do **not** touch the existing top-level `docs/` (reference material).
- Site URL: **`https://docs.healthcampaigns.org`**, `baseUrl: '/'`.
- GitHub repo slug: **`recodelabs/icr`**, default branch `main`.
- Cloudflare Pages project name: **`icr-docs`**. Reuse existing repo secrets **`CLOUDFLARE_API_TOKEN`** and **`CLOUDFLARE_ACCOUNT_ID`** (account `af8ac7eb1f7ec617e14702e69ce0d4c7`).

### Task 4: GitHub Actions deploy workflow

Add the build-and-deploy pipeline, mirroring `publish-ig.yml`.

**Files:**
- Create: `.github/workflows/publish-docs.yml`

**Interfaces:**
- Consumes: `website/` app (Task 1–3), repo secrets `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`, Pages project `icr-docs` (Task 5).
- Produces: on push to `main` touching `website/**`, a Cloudflare Pages deployment of `website/build`.

- [ ] **Step 1: Create `.github/workflows/publish-docs.yml`**

Full file content:

```yaml
name: Publish docs to Cloudflare Pages

# Builds the Docusaurus "ICR Implementation Guide" (website/) and deploys it to
# Cloudflare Pages project icr-docs (https://docs.healthcampaigns.org).
#
# Deploy requires two repo secrets (Settings → Secrets and variables → Actions):
#   CLOUDFLARE_API_TOKEN  — API token with "Cloudflare Pages: Edit" permission
#   CLOUDFLARE_ACCOUNT_ID — af8ac7eb1f7ec617e14702e69ce0d4c7
# Until they exist, the workflow still builds the site and uploads it as a
# run artifact; the deploy step is skipped.
on:
  push:
    branches: [main]
    paths:
      - "website/**"
      - ".github/workflows/publish-docs.yml"
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: publish-docs
  cancel-in-progress: true

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    env:
      CF_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
    steps:
      - name: Checkout icr
        uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: website/package-lock.json

      - name: Install dependencies
        run: cd website && npm ci

      - name: Build site
        run: cd website && npm run build

      - name: Upload site as run artifact
        uses: actions/upload-artifact@v4
        with:
          name: icr-docs-site
          path: website/build
          retention-days: 7

      - name: Deploy to Cloudflare Pages
        if: env.CF_TOKEN != ''
        uses: cloudflare/wrangler-action@v3
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          command: pages deploy website/build --project-name=icr-docs --branch=main
```
